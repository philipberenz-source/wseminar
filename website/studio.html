Kurzanleitung

  

    
So funktioniert’s: Beim Start lädt der Browser Python (Pyodide) mit NumPy und führt den unveränderten Kern fdtd_core.py aus der Seminararbeit aus. Die Rechnung läuft in einem Hintergrund-Thread (Web Worker). Die Oberfläche zeigt nur die Ergebnisse an.

Szenen werden im selben JSON-Format gespeichert wie im Desktop-Studio (fdtd_studio.py). Dateien lassen sich also in beide Richtungen austauschen.

    
Energie wird wie im Desktop-Studio zeitlich verschränkt gebildet, Wn = Δ²Σ(ε Ezn²/2 + μ Hn−½·Hn+½/2). Ohne Verluste bleibt sie dadurch exakt erhalten, zum Beispiel im PEC-Resonator.

    
Intensitätsschirm zeigt das Zeitmittel ⟨Ez²⟩ längs einer Spalte i (gestrichelte Linie im Feld), bezogen auf sein Maximum. Im linearen Modus sind die Maxima mit ihrem Index j beschriftet. Da das Mittel ab dem Start läuft, enthält es auch das Einschwingen. „Mittelung neu starten“ beginnt es von vorn, sobald sich ein stationäres Bild eingestellt hat.

    
Stabilität: Bei einer Courant-Zahl S > 1 divergiert die Rechnung. Das Studio stoppt dann automatisch.
